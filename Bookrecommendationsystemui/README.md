
  # Book Recommendation System UI

  This is a code bundle for Book Recommendation System UI. The original project is available at https://www.figma.com/design/FJnxWPBNF6nchCVgZq0iqf/Book-Recommendation-System-UI.

  ## Running the code

  Run `npm i` to install the dependencies.

  Optional: set backend API URL (default is `http://127.0.0.1:8000/api/v1`):

  ```bash
  export VITE_API_BASE_URL=http://127.0.0.1:8000/api/v1
  ```

  Run `npm run dev` to start the development server.
